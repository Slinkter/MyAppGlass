# src/components/ui

Snippets de **Chakra UI v3** generados por el CLI (`npx @chakra-ui/cli snippet add ...`): `dialog`, `field`, `checkbox`, `provider`, etc.

- Son código de terceros adaptado: **están exentos** de la convención de nombres PascalCase del proyecto (se conservan en kebab-case tal como los genera el CLI).
- No colocar aquí componentes de negocio; para eso usar `src/shared/components`, `src/widgets` o la feature correspondiente.
