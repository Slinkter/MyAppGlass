## 1. Resumen ejecutivo

La empresa tiene lo más difícil: **taller propio, equipo estable, formalidad tributaria, show room y cinco distritos con proyectos**. El problema no es la capacidad de ejecutar obras; es que **casi nada de eso se puede verificar antes de la primera llamada**. La marca pierde fuerza en tres puntos:

1. **Prueba insuficiente:** solo 2 o 3 obras tienen fotos completas y el show room no se muestra.
2. **Mensaje disperso:** varias frases de marca, nombres cortos distintos y afirmaciones de «líderes» que no se sostienen con evidencia.
3. **Activos de marca incompletos:** el sistema visual ya está alineado, pero no existe logo horizontal ni versión monocromo.

La propuesta es **ordenar la prueba, unificar el mensaje y captar mejor**, en tres horizontes. No requiere más personal: requiere disciplina y dos o tres activos externos (fotos y logo).

**Resultado esperado a 180 días:** una marca que se puede verificar, un sitio que responde a las búsquedas reales de los cinco distritos y un panel mensual de leads y cierres. Los resultados de SEO no se garantizan; se miden.

## 10. Cómo se aplica al proyecto (plan de ejecución)

### 10.1 Método

- Se trabaja en una **rama/worktree aparte**. `main` y el sitio publicado no se tocan.
- Cada lote termina con `pnpm run typecheck && pnpm run build`, captura de pantalla y **commit en la rama**.
- El deploy se hace **solo** cuando el dueño lo pida, después de aprobar el lote.
- **No se esperan activos para arrancar.** Cada lote tiene un «modo sin activos»: publica lo verificable y marca el resto `[Pendiente]`. No se usan fotos de terceros, stock ni datos inventados.
