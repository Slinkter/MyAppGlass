# Sesión 2 · AI Frontend Engineering · Código y material de talleres

Diploma Ingeniería de Software con IA · DMC · Docente: Jorge Lozano

| Carpeta | Taller | Duración |
|---|---|---|
| `taller-1-wireframes-figma-ai/` | Construcción inicial de wireframes con Figma AI (Figma Make) para TurnoYa | 35 min |
| `taller-2-claude-code/` | Integración de Claude Code al entorno de desarrollo (Windows + VS Code) | 40 min |

Cada taller tiene un `README.md` con los pasos, una carpeta `inicio/` (punto de partida)
y una carpeta `final/` (resultado esperado para comparar).

## Antes de la clase
1. Cuenta gratuita de Figma (plan Starter) con sesión iniciada en el navegador.
2. Cuenta de Claude Pro, Max, Team, Enterprise o Console (Claude Code no está en el plan gratuito).
3. Git for Windows y VS Code 1.94+ instalados, con la extensión Live Server.
4. Ejecuta `taller-2-claude-code/verificar-entorno.ps1` y corrige lo que marque `[FALTA]`.

## Cómo se conectan
Taller 1 produce el wireframe aprobado del catálogo (`01-catalogo.png`).
Taller 2 lo usa como contexto para que Claude Code implemente la HU-01 con revisión humana en cada paso.
